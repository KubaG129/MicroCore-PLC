# MicroCore-PLC

A lightweight, multithreaded control system emulator developed in modern C++17 to simulate the execution cycle of an industrial programmable logic controller.
## Important parts of the project
* [x] Integrated **Catch2** framework for automated Unit Testing.
* [x] Implemented **Python** utility script to feed mock telemetry data via CSV and parse execution logs (100 rows of data).
* [x] Configured a **GitHub Actions** CI workflow to automate cross-platform compilation and verification.
