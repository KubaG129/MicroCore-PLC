# MicroCore-PLC

A lightweight, multithreaded control system emulator developed in modern C++17 to simulate the execution cycle of an industrial programmable logic controller.
## Project Roadmap
* [x] Integrate **Catch2** framework for automated Unit Testing.
* [x] Implement **Python** utility scripts to feed mock telemetry data via CSV and parse execution logs.
* [x] Configure a **GitHub Actions** CI workflow to automate cross-platform compilation and verification.
